Where to access GPUs
Hunter Creech (Luter 221) has dual boot machines configured for this class. The Linux partition has a complete deeplearning dev environment with access to a 24gB Nvidia RTX 4090 GPU.
If you have a desktop GPU that has 24 GB of VRAM or more Then you can probably run most of the course notebooks locally. (If your GPU is in a laptop then you will not be able to do much given the amount of VRAM in laptop GPUs)
If you would like to use cloud providers like Google Colab, Amazon SageMaker, or Microsoft Azure, then please consult this page for more information (these are not free!). You should prefer this method since it gives you maximum flexibility in machine configuration and you will probably use it professionally.
