Broadcasting in PyTorch Broadcasting is a powerful mechanism that allows PyTorch to work with tensors of different shapes when performing arithmetic operations. The smaller tensor is "broadcast" across the larger tensor so that they have compatible shapes. This is particularly useful for operations like normalization, where you want to apply the same operation across different dimensions of a tensor without explicitly reshaping it.

6 Fine tuning pre trained models for Image Classification using Pytorch Image Models (timm)

You dont create CNNs from scratch, you use pre trained models and finetune them to your dataset (also called transfer learning). This is much faster, takes less data, and lowers the bar in terms of needed expertise.
timm has 700+ pre trained models, many SOTA

How to choose a model for classification:
In general prefer models in the following families; convnext, vit, swin (and v2) and EfficientNet (and v2).
  • Accuracy paramount? Use a larger model like deeper ResNets, larger EfficientNets, or state-of-the-art ViTs.
  • Speed/inference time paramount? Use a smaller model like MobileNetV3, EfficientNet-lite, or a small ResNet.
  • Dataset very different from training dataset? Use a smaller model like vit_small_patch or conv_next_tiny
Larger models are more accurate but take longer to train, are slower, and require more memory and compute. Smaller models are less accurate but faster.

NOTE:
  • Use timm.list_models() to see all available models. You can filter by architecture (e.g., timm.list_models('*resnet*')).
  • Use timm.create_model('model_name', pretrained=True, num_classes=num_classes) to create a model. Make sure you set num_classes to the number of classes in your dataset. Also make sure you set pretrained=True when you create the model for fine tuning. Otherwise you have to train the model from scratch.
  • Examine the default configuration of a model with model.default_cfg to understand expected input size, normalization parameters (mean and std), and other relevant details.
